# BOKT-next — фронтенд

Консоль операций для бэкенда **BOKT-next**: React 18 + Vite 5 + MUI 5.
Двухшаговый вход (пароль → OTP), авто-обновление токенов, навигация с фильтром по правам,
страницы под каждый модуль бэка.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Запросы `/api` и `/actuator` проксируются на бэкенд
(`http://localhost:8080` по умолчанию). Другой адрес — переменной окружения:

```bash
VITE_BACKEND_URL=http://localhost:9090 npm run dev
```

Бэкенд должен быть запущен (см. его README / docker-compose).

## Вход

1. Логин организации `platform`, пользователь `superadmin`, пароль — из настроек бэкенда
   (`BOKT_SUPERADMIN_PASSWORD`) или из лога при первом старте.
2. После шага 1 приходит OTP. Реальный SMS-шлюз не подключён, поэтому код **печатается в лог
   бэкенда** (заглушка). Введите его на втором шаге.

## Что внутри

- `src/api/` — axios-клиент с авто-refresh (`client.js`) и обёртки по модулям
  (auth, organisations, branches, roles, users, clients, credits, files, audit).
- `src/auth/` — контекст авторизации (`AuthContext`), защита маршрутов (`ProtectedRoute`).
  Права берутся из JWT (claim `authorities`), меню и кнопки скрываются по правам.
- `src/pages/` — страницы: Обзор, Кредиты (создание, подтверждение, отмена, отложение,
  возврат, поиск по PAN), Клиенты, Импорт кредитов, Пользователи, Роли, Филиалы,
  Организации (NBCO), Аудит.
- `src/theme.js` — тема оформления (чернильно-синий, зелёный акцент денег, моно-шрифт для
  сумм/RRN/PAN, табличные цифры).

## Сборка

```bash
npm run build      # → dist/
npm run preview    # предпросмотр собранной версии
```

> Зависимости не устанавливались при подготовке проекта (не было сети). Перед запуском —
> `npm install`; при необходимости обнови версии в `package.json`.
